# Claude Code 项目配置

## 语言偏好设置

**重要：本项目所有交互必须使用中文简体**

### 交流语言规范

1. **对话语言**：所有对话交流使用中文简体
2. **代码注释**：所有代码注释使用中文简体
3. **文档生成**：所有生成的文档（如 README、说明文档等）使用中文简体
4. **错误处理**：错误提示、警告信息等使用中文简体
5. **提交信息**：Git commit 信息使用中文简体
6. **变量命名**：代码变量、函数名等仍使用英文（遵循编程规范），但相关注释和说明用中文

### 项目信息

- **项目名称**：小红书克隆项目
- **技术栈**：Next.js 15 + React 19 + TypeScript + Prisma + NextAuth
- **开发环境**：Windows (MINGW64)

### 代码风格

- 使用 TypeScript 进行类型约束
- 使用 Prettier 格式化代码
- 使用 ESLint 进行代码检查
- 所有注释和文档说明使用中文简体

### 注意事项

- 确保所有生成的内容都是中文简体
- 代码逻辑说明、算法解释等都用中文
- 保持专业、简洁的中文表达
